## Deskripsi
Repositori ini berisi tugas praktikum mata kuliah Kecerdasan Buatan yang menggunakan dataset AirPassenger untuk melakukan audit data, preprocessing, Exploratory Data Analysis (EDA), serta pemodelan klasifikasi untuk memprediksi tingkat kepuasan penumpang pesawat.

## Isi Repositori
- `Praktikum_AI_AirPassenger.ipynb` — Notebook pengerjaan praktikum.
- `Air_Passanger_Dataset.zip` — Dataset yang digunakan.
- `output/` — Hasil analisis dan visualisasi.
- `requirements.txt` — Daftar pustaka Python yang diperlukan.
- `Ringkasan_Analisis_AI_AirPassenger.pdf` — Ringkasan hasil analisis.

## Tujuan
Menerapkan tahapan pengolahan data dan metode pembelajaran mesin untuk menganalisis faktor-faktor yang berkaitan dengan kepuasan penumpang pesawat.
